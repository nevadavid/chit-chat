# Chit-chat (Real-time Chat App)

Real-time multi-user chat application

🔸 Node.js (Express) + Socket.IO backend

🔸 React + Tailwind frontend

## 🚀 Features / TODO

- [x] users listing
- [x] registration
- [x] message sending
- [ ] Redux
- [ ] only new message(s) event
- [ ] private message
- [ ] "user is typing"

- [ ] DB: Firebase Free Tier
- [ ] Auth: Firebase Authentication
- [ ] Real-time chat: Firebase realtime events

## Install

```bash
# Backend
cd server
npm install
npm run dev

# Frontend
cd ../client
npm install
npm run dev
```
